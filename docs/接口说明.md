# 接口说明

本文档记录绝区零（CN 服）每日签到涉及的接口、签名算法与返回码，供排查问题时参考。

> 接口为米游社客户端/网页行为的外部观察结果，**非官方文档**，可能随官方更新而变化。

| 用途 | 方法 | URL |

### 参数

**签到状态查询**（query）

```
act_id=e202406242138391&region=<服务器>&uid=<角色UID>
```

**执行签到**（JSON body，键名字母序）

```json
{"act_id":"e202406242138391","region":"prod_gf_cn","uid":"10000001"}
```

**角色列表**（query）

```
game_biz=nap_cn
```

**stoken 换 token**（query + stoken 形式的 Cookie）

```
stoken=<stoken>&uid=<stuid>
Cookie: stuid=<stuid>;stoken=<stoken>[;mid=<mid>]
```

## 4. DS 签名算法

签名必须与 **salt / `x-rpc-app_version` / `x-rpc-client_type`** 整体配对，否则返回 `retcode = -1`。

### DS1（基础版）

```
raw = "salt={salt}&t={t}&r={r}"
DS  = "{t},{r}," + md5_hex_lower(raw)
```

| 参数 | 说明 |
|---|---|
| `t` | **秒级** Unix 时间戳 |
| `r` | 6 位 `[a-z0-9]` 随机字符串 |

### DS2（带 body / query）

```
raw = "salt={salt}&t={t}&r={r}&b={body}&q={query}"
DS  = "{t},{r}," + md5_hex_lower(raw)
```

| 参数 | 说明 |
|---|---|
| `r` | **100001–200000** 的整数 |
| `b` | POST body 的**键名字母序紧凑 JSON** |
| `q` | GET query 按键名字母序拼接的 `k=v&k=v` |

### 关键要点

- 使用 **UTF-8** 编码后计算 MD5，输出**小写十六进制**
- **DS1 与 DS2 的 `r` 类型不同**（6 位字符串 vs 整数），混用必定签名失败
- 时间戳偏差超过约 5 分钟会失败，因此**不要复用缓存的 DS**
- `b` 与 `q` 必须与实际发送的内容**逐字节一致**，否则签名与服务端计算结果不符

## 5. 返回码

| retcode | 含义 | 处置 |
|---|---|---|
| `0` + `data.success == 0` | 签到成功 | 正常完成 |
| `0` + `data.success == 1` | 需要验证码/风险校验 | 不重试，提示用户手动签到 |
| `-5003` | 今日已签到 | **视为成功**（幂等） |
| `-1` | DS 签名无效 | 切换签名模式重试一次 |
| `-100` | Cookie 失效 | 用 stoken 刷新后重试一次 |
| `1034` | 需要验证码 | 不重试 |
| `429` | 请求过于频繁 | 指数退避重试 |
| `10001` | 未绑定该游戏角色 | 检查账号绑定 |

## 6. 凭证体系

| 名称 | 有效期 | 用途 |
|---|---|---|
| `cookie_token` | 约 1 天 | 主要鉴权凭证 |
| `ltoken` | 约 1 天 | 同上 |
| `stoken` | 约 30 天 | 用于**自动换取**新的 `cookie_token` |
| `mid` | 长期 | v2 形态的 stoken 必需 |

### 刷新流程

```
cookie_token 失效（retcode = -100）
        │
        ▼
用 stoken 调 getCookieAccountInfoBySToken
        │
    ┌───┴───┐
   成功    失败
    │       │
    ▼       ▼
把新 token  提示用户重新提取凭证
合入 Cookie
```

**v2 形态的 stoken**（以 `v2_` 前缀开头）需要额外提供 `mid`，否则无法刷新。

`%LOCALAPPDATA%\ZzzAutoSign\endpoints.json` 可覆盖内置常量，**无需重新编译**：

```json
{
  "actId": "e202406242138391",
  "zzzWebApi": "https://act-nap-api.mihoyo.com",
  "apiTakumi": "https://api-takumi.mihoyo.com",
  "actOrigin": "https://act.mihoyo.com",
  "saltWeb": "DlOUwIupfU6YespEUWDJmXtutuXV6owG",
  "saltX6": "t0qEgfub6cvueAPgR5m9aQWWVciEer7v",
  "saltApp": "b0EofkfMKq2saWV9fwux18J5vzcFTlex",
  "appVersion": "2.99.1",
  "channel": null
}
```

只覆盖你显式提供的字段，其余保留默认值。

### 如何自己抓取新的 salt

1. 打开 Chrome，登录米游社
2. `F12` → `Network` 标签
3. 访问绝区零签到页面并完成一次签到
4. 找到发往 `act-nap-api.mihoyo.com` 的 `sign` 请求
5. 查看请求头里的 `DS` 与 `x-rpc-app_version`
6. 参考本文档的算法推导 salt
