# 凭证获取指南

本文档说明如何获取米游社登录凭证并交给主程序使用。

---

## 为什么不能直接用账号密码

米哈游通行证的密码登录接口（`account.mihoyo.com/Api/login_by_password`）**强制要求极验（Geetest）行为验证码**。请求必须携带以下字段之一：

- 三代验证：`geetest_challenge`、`geetest_validate`、`geetest_seccode`
- 四代验证：`geetest_v4_data`（含 `lot_number`、`captcha_output`、`pass_token`、`gen_time`、`captcha_id`、`sign_token`）

这些字段由真实浏览器中的鼠标轨迹与行为数据生成，**无法通过纯 HTTP 请求伪造**。

绕过它的办法只有两类，都不适合个人使用：

| 办法 | 问题 |
|---|---|
| 接第三方打码平台 | 需要付费，且**必须把你的账号密码发送到第三方服务器** |
| 用自动化浏览器填表登录 | 需要额外环境，且米游社风控对自动化浏览器识别敏感，账号有被标记的风险 |

因此本项目采用**半自动方案**：你在真实浏览器里亲自登录一次，工具只负责把登录后的 Cookie 读出来。**账号密码始终不离开你的电脑。**

## 前置条件

用 Chrome、Edge 或 Firefox 登录过米游社：

<https://www.miyoushe.com/>

建议登录后先手动访问一次绝区零签到页面，确保账号已绑定游戏角色。

---

## 方式 A：打开浏览器登录（推荐）

1. 运行 `CredentialGrabber.exe`
2. 点顶部的 **「打开浏览器登录」**
3. 程序会启动一个浏览器窗口，自动打开米游社首页
4. **在浏览器窗口里正常登录**（扫码、短信、密码都行，随你方便）
5. 登录成功后，工具会自动检测到登录态

```
检测到登录态，正在读取凭证…
凭证已加密保存：
  Cookie 长度：xxx
  stoken：abcd***wxyz
  stuid：123456789
  写入位置：C:\Users\你\AppData\Local\ZzzAutoSign\credential.bin
```

6. 看到成功提示即可关闭工具

> **提示**：如果程序提示找不到浏览器，请先安装 Chrome 或 Edge。若使用内置 Chromium，需要在工具目录执行 `.\playwright.ps1 install chromium` 安装内核。

---

## 方式 B：F12 控制台脚本

适合不想让程序启动浏览器的情况，或者方式 A 读不到 stoken 时的补充手段。

### 步骤

1. 用你自己的浏览器打开并登录 <https://www.miyoushe.com/>
2. 按 `F12` 打开开发者工具，切到 **Console（控制台）** 标签
3. 如果控制台显示「不允许粘贴」，按提示输入 `allow pasting` 并回车
4. 回到 `CredentialGrabber.exe`，点 **「复制控制台脚本」**
5. 把脚本粘贴到控制台，回车执行

脚本会输出类似内容：

```json
{
  "cookie": "cookie_token=...; ltoken=...; ltuid=...",
  "stoken": "...",
  "stuid": "123456789",
  "mid": "...",
  "_source": "www.miyoushe.com",
  "_time": "2026-09-16T00:00:00.000Z"
}
```

同时自动复制到剪贴板，并弹出一个确认提示。

6. 回到工具，把内容粘贴到「粘贴凭证」输入框
7. 点 **「解析并保存」**

> 输入框同时接受**完整 JSON** 和**裸 Cookie 串**（形如 `a=b; c=d`）两种格式。若只粘 Cookie 串，工具会尝试从中提取 `stuid` 和 `mid`。

---

## 该保留哪些字段

| 字段 | 是否必需 | 说明 |
|---|---|---|
| `cookie_token` | ✅ | 主要鉴权凭证，约 1 天有效 |
| `ltoken` | ✅ | 同上 |
| `stuid` / `ltuid` | ✅ | 账号 UID |
| `stoken` | ⭐ **强烈建议** | 约 30 天有效；有了它，`cookie_token` 失效时程序能自动刷新 |
| `mid` | 视情况 | 仅当 stoken 是 `v2_` 前缀的形态时才需要 |

**没有 stoken 会怎样**：`cookie_token` 大约每 1 天失效一次，届时程序会通知你「登录凭证已失效」，你需要重新提取。有 stoken 的话，大约每月重新提取一次就够了。

---

## 凭证存放在哪里

写入路径：

```
%LOCALAPPDATA%\ZzzAutoSign\credential.bin
```

即 `C:\Users\<你的用户名>\AppData\Local\ZzzAutoSign\credential.bin`

**安全措施**：

- 使用 Windows **DPAPI**（用户作用域）加密
- **只有当前 Windows 用户**能解密；换用户或换机器都读不出来
- 每次写入前会自动备份为 `credential.bin.bak`
- 文件用记事本打开是乱码

## 验证凭证是否可用

### 方法一：工具内置检查

在 `CredentialGrabber.exe` 里点 **「检查已有凭证」**，会显示：

```
已找到凭证，摘要如下：
  Cookie 长度：xxx
  stoken：abcd***wxyz
  stuid：123456789
  mid：abcd***wxyz
  保存时间：2026-09-16 08:30:00
```

### 方法二：主程序测试

1. 运行 `ZzzAutoSign.exe`（管理员）
2. 右键托盘图标 → **「立即签到」**
3. 看到「绝区零签到完成」即表示凭证正常

---

## 凭证过期怎么办

| 情况 | 表现 | 处理 |
|---|---|---|
| `cookie_token` 过期 | 通知「登录凭证已失效」 | 若配了 `stoken` 会自动刷新；否则重新提取 |
| `stoken` 过期 | 刷新失败，仍报凭证失效 | 重新提取一次（约每月一次） |
| 修改了米游社密码 | 所有凭证立即失效 | 重新提取 |

> 修改密码会使所有已签发的凭证失效，这是米哈游的安全策略，无法规避。

---

## 安全提醒

- Cookie 等同于你的登录态，**请勿分享给任何人**
- 不要把 `credential.bin` 上传到网盘或代码仓库（项目的 `.gitignore` 已排除相关文件）
- 本工具不联网传输你的凭证，所有请求只发往米游社官方域名
- 建议不要使用来源不明的同类工具，它们可能收集你的 Cookie
