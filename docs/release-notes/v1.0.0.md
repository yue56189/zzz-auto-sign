首个正式版本。绝区零（Zenless Zone Zero）每日自动签到工具，Windows 托盘常驻。

## 下载

| 文件 | 用途 | 体积 |
|---|---|---|
| `ZzzAutoSign-win-x64.zip` | 主程序：托盘、定时签到、桌面通知 | 69.1 MB |
| `CredentialGrabber-win-x64.zip` | 登录凭证提取工具（Playwright） | 91.5 MB |
| `SHA256SUMS.txt` | 上面两个压缩包的 SHA256 校验和 | 188 B |

自包含单文件发布，**无需另外安装 .NET 运行时**，解压即用。仅支持 Windows x64。

校验下载（PowerShell）：

```powershell
Get-FileHash .\ZzzAutoSign-win-x64.zip -Algorithm SHA256
# 与 SHA256SUMS.txt 中的值比对
```

## 已知限制

- **签名依赖 salt**：米哈游接口的 DS 签名与 `x-rpc-app_version` / salt 强耦合，
  官方更新客户端后可能失效。届时需重新抓取并写入 `%LOCALAPPDATA%\ZzzAutoSign\endpoints.json`
  （见 README 与 `docs/排障手册.md`）。
- **真机行为尚未完整验证**：托盘图标、Toast 通知、WMI 进程监听等需要在有账号的
  Windows 机器上实际跑一遍，核对清单见 `docs/实施与验证记录.md`。
- 本项目**未附带开源许可证**，默认保留所有权利。
