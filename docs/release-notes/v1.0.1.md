修复 `CredentialGrabber.exe` 无法启动的问题。**这是补丁版本，建议所有用户升级。**

## 修了什么

**`CredentialGrabber.exe` 一启动就报
`Driver not found: …\.playwright\node\win32_x64\node.exe`，工具完全无法使用。**

原因是打包时 Playwright 的 node 驱动被静默丢掉了：单文件发布会把
`.playwright\node\win32_x64\node.exe` 当成「原生库」从产物里剔除，却又没有真正打进 exe。
而 `.playwright\package\` 和 LICENSE 都还在，所以发布目录**看上去完全正常**，
只有运行时才失败。

已在 `CredentialGrabber.csproj` 增加目标 `EnsurePlaywrightDriverIsPublished`：
在发布复制之前把驱动目录重新挂回产物；`build.yml` / `release.yml` 另加了硬断言，
驱动缺失就让构建直接失败，不再发布装不上驱动的包。

> **如果你下载过 `v1.0.0`**：其中的 `ZzzAutoSign-win-x64.zip`（主程序）可以正常使用，
> 只有 `CredentialGrabber-win-x64.zip` 是坏的。请改用本版本的抓取工具。

## 下载

| 文件 | 用途 | 体积 |
|---|---|---|
| `ZzzAutoSign-win-x64.zip` | 主程序：托盘、定时签到、桌面通知 | 69.1 MB |
| `CredentialGrabber-win-x64.zip` | 登录凭证提取工具（本次修复的就是它） | — |
| `SHA256SUMS.txt` | 上述两个压缩包的 SHA256 校验和 | — |

自包含单文件发布，**无需另外安装 .NET 运行时**。仅支持 Windows x64。

> **解压整个压缩包，不要只把 exe 拿出来。**
> `CredentialGrabber.exe` 依赖同目录下的 `.playwright\` 文件夹，少了它就报
> `Driver not found`。详见 [排障手册](https://github.com/yue56189/zzz-auto-sign/blob/main/docs/排障手册.md)。

校验下载（PowerShell）：

```powershell
Get-FileHash .\CredentialGrabber-win-x64.zip -Algorithm SHA256
# 与 SHA256SUMS.txt 中的值比对
```

## 已知限制（与 v1.0.0 相同）

- **签名依赖 salt**：米哈游接口的 DS 签名与 `x-rpc-app_version` / salt 强耦合，
  官方更新客户端后可能失效，届时需重新抓取 `endpoints.json`（见 README 与排障手册）。
- **真机行为尚未完整验证**：托盘图标、Toast 通知、WMI 进程监听等需要在有账号的
  Windows 机器上实际跑一遍，核对清单见 `docs/实施与验证记录.md`。
